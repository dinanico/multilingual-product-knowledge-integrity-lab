# Contributing

Contributions should preserve the project's reproducible, fictional-first scope.

- Run `python -m pytest -q` before submitting a change.
- Prefer deterministic fixtures and NexaVolt-style fictional examples.
- Never add customer data, real manufacturer evidence, secrets, raw provider responses, or local paths.
- Keep Product Truth, observed AI output, and QA findings separate.
- Do not add proprietary scoring, commercial prioritization, or workflow-platform features.
